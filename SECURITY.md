# Security Policy 🛡️

The maintainers of `agent-verify` take security and safety vulnerabilities seriously.

## 📦 Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

---

## 🚨 Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you believe you have discovered a vulnerability, bypass bug, anti-gaming evasion, or security issue in `agent-verify`, please report it privately:

1. **Email**: Send details to **`jrnikiljr@gmail.com`**.
2. **Details to Include**:
   - Description of the vulnerability and attack vector.
   - Proof-of-concept repository, diff, or script demonstrating evasion or exploit.
   - Any proposed remediation or patches.

### ⏱️ Response Timeline

- **Initial Acknowledgment**: Within 48 hours.
- **Triage & Assessment**: Within 7 business days.
- **Fix & Advisory Release**: Coordinated disclosure within 90 days of confirmation.

---

## 🔒 Scope & Research Guidelines

We welcome research into:
- Anti-gaming detection evasion (e.g. bypassing test mutation scans).
- Subprocess sandbox breakouts during test runner execution.
- AST parsing denial-of-service or memory consumption issues.
- Git diff parsing inconsistencies leading to false VERIFIED claims.

Please adhere to responsible disclosure principles and allow reasonable time for a fix before making details public.
